# 🎵 Music Store Data Analysis using MySQL

## 📌 Project Overview

Music Store Data Analysis is a SQL-based data analysis project
using a relational music store database.

The project focuses on analyzing customers, invoices, tracks,
artists, albums, genres and purchase transactions using MySQL.

## 🎯 Objectives

- Understand relational database structure
- Create and manage tables
- Work with primary and foreign keys
- Analyze customer purchases
- Analyze sales by country and city
- Identify popular genres and artists
- Identify top customers
- Practice SQL joins and aggregations
- Use subqueries, CTEs and window functions

## 🗄️ Database Tables

- Employee
- Customer
- Artist
- Album
- Track
- Genre
- MediaType
- Invoice
- InvoiceLine
- Playlist
- PlaylistTrack

## 🛠️ Technologies Used

- MySQL
- MySQL Workbench
- SQL

## 📊 Analysis Performed

1. Senior-most employee
2. Countries with the most invoices
3. Top 3 invoice values
4. City with highest sales
5. Best customer
6. Rock music listeners
7. Top 10 Rock artists
8. Tracks longer than average
9. Customer spending by artist
10. Most popular genre by country
11. Top customer by country
